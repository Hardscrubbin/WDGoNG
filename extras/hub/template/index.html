WatchDogsGo NG Extras

Reviewed community mini-apps. Signed catalogue, checksum-verified, and always run in a sandbox on the device.
Official extras (green ✓ LOCOSP) are made by LOCOSP. All others are made by their own authors, not by LOCOSP. Install and run only what you know and trust — at your own risk.

Rate an extra: open its vote link and react with 👍 (banana = yes) or with 👎 (peel = no). One vote per GitHub account; counts refresh every few hours.

Install: open EXTRAS › Hub in the game — it verifies the signature and each extra's checksum before installing, and runs every extra sandboxed.

Publish one: read the author guide, test it with tools/run_in_sim.py <dir> 30 --sandbox, and open a pull request.
